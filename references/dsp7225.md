> Pymeasure reference. Original prose; identifiers preserved verbatim.

### DSP 7225 Lock-in Amplifier

 *class *pymeasure.instruments.signalrecovery.DSP7225(*adapter*, *name='Signal Recovery DSP 7225'*, ***kwargs*)

Bases: `DSPBase`

Models the Signal Recovery DSP 7225 lock-in amplifier.

This class takes its commands from the DSPBase parent class and uses dynamic properties for several properties.

```python
lockin7225 = DSP7225("GPIB0::12::INSTR")
lockin7225.imode = "voltage mode"       # Set to measure voltages
lockin7225.reference = "internal"       # Use internal oscillator
lockin7225.fet = 1                      # Use FET pre-amp
lockin7225.shield = 0                   # Ground shields
lockin7225.coupling = 0                 # AC input coupling
lockin7225.time_constant = 0.10         # Filter time set to 100 ms
lockin7225.sensitivity = 2E-3           # Sensitivity set to 2 mV
lockin7225.frequency = 100              # Set oscillator frequency to 100 Hz
lockin7225.voltage = 1                  # Set oscillator amplitude to 1 V
lockin7225.gain = 20                    # Set AC gain to 20 dB
print(lockin7225.x)                     # Measure X channel voltage
lockin7225.shutdown()                    # Instrument shutdown

```

 buffer_to_float(*buffer_data*, *sensitivity=None*, *sensitivity2=None*, *raise_error=True*)

Translate fixed-point buffer data into floating point data.

Conversion is attempted for as much of the supplied data as possible, but converting all supplied columns depends on data requirements; any key that cannot be converted is either left out of the returned data or triggers an exception, according to raise_error.

These are the requirements for data conversion:

-

To convert X, Y, magnitude and noise, sensitivity data is required; that data may be included in the supplied data or passed with the sensitivity argument.

-

The same rule applies to X2, Y2 and magnitude2 when using sensitivity2.

-

Frequency conversion needs both ‘frequency part 1’ and ‘frequency part 2’.

Parameters:

-

**buffer_data** (*dict*) – Data slated for conversion. It must use the format returned by the get_buffer method: a dict of numpy arrays.

-

**sensitivity** – Optional sensitivity value used when converting X, Y, magnitude and noise. It may be a float, or an array whose length matches elements in buffer_data. When sensitivity is supplied and buffer_data also contains sensitivity, conversion uses the supplied value, while the sensitivity from buffer_data is kept in the returned dict. (default: `None`)

-

**sensitivity2** – Equivalent to the first sensitivity argument, except it applies to X2, Y2, magnitude2 and noise2. (default: `None`)

-

**raise_error** (*bool*) – Controls whether an exception is raised when some keys in buffer_data cannot be converted. If False, unconvertible columns are left out of the returned dict.

Returns:

Floating-point buffer data

Return type:

dict

 *property *complete

Use this property to synchronize a controller with a device. The Operation Complete query puts ASCII character 1 in the device’s Output Queue once every pending selected device operation has finished.

 *property *coupling*: Any*

Control the input coupling mode.

 *property *curve_buffer_bits*: Any*

Choose which data outputs are saved in the curve buffer.

Allowed values are integers from 1 through 65,535, or through 2,097,151 in dual reference mode. (dynamic)

 *property *curve_buffer_interval*: Any*

Set the time interval between collection of successive curve-buffer points.

The time interval accepts integer ms values at 5 ms resolution; inputs are rounded up to a multiple of 5. Allowed values run from 0 to 1,000,000,000, corresponding to 12 days. Setting the interval to 0 changes data storage in the curve buffer to 1.25 ms/point (800 Hz). That mode only permits storage of the X and Y channel outputs. A CBD 3 command is unnecessary for this setup, because acquisition start performs it automatically.

 *property *curve_buffer_length*: Any*

Set the curve buffer length.

Allowed values are integers from 1 through 32,768, but the actual maximum point count depends on how many curves are stored, as configured by the curve_buffer_bits property (32,768 / n).

 *property *curve_buffer_status*: Any*

Measure curve buffer acquisition status.

The command returns four values. **First value - Curve Acquisition Status:** This status number has 5 possibilities: state 0 means no activity; state 1 means acquisition via TD command is running; state 2 means acquisition by a TDC command is running; state 5 means acquisition via TD command is halted; state 6 means acquisition via TDC command is halted. **Second value - Number of Sweeps Acquired**: gives the sweeps already acquired. **Third value - Status Byte:** reports the status byte as a decimal value and matches the ST command response. **Fourth value - Number of Points Acquired:** gives the point count acquired in the curve buffer.

 get_buffer(*quantity=None*, *convert_to_float=True*, *wait_for_buffer=True*)

Retrieve the buffer after filling completes. Data read from the lock-in uses fixed-point format and must be translated before it can be understood as meaningful data. When convert_to_float is True, conversion is performed before the data is returned, if possible.

Parameters:

-

**quantity** (*str*) – Optional name of the quantity to retrieve from the curve buffer. Valid choices include ‘x’, ‘y’, ‘magnitude’, and ‘phase’; also ‘sensitivity’, ‘adc1’, ‘adc2’, ‘adc3’, ‘dac1’, and ‘dac2’; plus ‘noise’, ‘ratio’, ‘log ratio’, ‘event’, ‘frequency part 1’, and ‘frequency part 2’. In both dual modes, the extra choices are ‘x2’, ‘y2’, ‘magnitude2’, ‘phase2’, and ‘sensitivity2’. If quantity is not provided, every available data item is retrieved.

-

**convert_to_float** (*bool*) – Bool selecting whether fixed-point buffer-data is converted through the buffer_to_float method into meaningful floating point values. If True, this method attempts to convert all available data into meaningful values; failure to do so raises an exception. If False, conversion is skipped and raw buffer-data is returned.

-

**wait_for_buffer** (*bool*) – Bool selecting whether to wait for data acquisition to finish when this method is called before completion. If True, execution waits until the buffer is filled. If False, an exception is raised if acquisition has not finished at call time.
