 *property *conversion_loss*: Any*

Set the loss compensation used outside the instrument in external mixer mode, including connector-cable losses, external mixers, etc. `conversion_loss` gives the mean conversion loss for the current harmonic band. For a full frequency band, such as band K, compute the mean conversion loss by adding that band's minimum loss and maximum loss, then dividing by two. Applying this conversion-loss adjustment keeps the system calibrated, so displayed amplitude values include the conversion loss. The default for any band is 30 dB. This command works only when the spectrum analyzer is in external-mixer mode. In internal-mixer mode, a `conversion_loss` query returns a zero.

 *property *harmonic_number_lock*: Any*

Lock operation to one selected harmonic so sweeping an external frequency band uses no other harmonic. Use the `fullband` command to choose a frequency band; it selects a suitable harmonic for that band. Change the harmonic number with `harmonic_number_lock`. `harmonic_number_lock` also works in internal-mixing modes. After `fullband` or `harmonic_number_lock` is set, entered center frequencies and spans must be inside the frequency band for the active harmonic. Activating `set_full_span` limits the span to the selected harmonic's frequency band.

 *property *harmonic_number_lock_enabled*: Any*

Turn harmonic number locking on or off. See `harmonic_number_lock`.

 *property *mixer_bias*: Any*

Set external-mixer bias when efficient mixer operation requires diode bias. MBIAS activates the bias on the center conductor of the IF input. A `+` or `-` appears at the left edge of the spectrum analyzer display to show positive or negative bias. Turning bias off sets MBIAS to 0. Default units are milliamps.

 *property *mixer_bias_enabled*: Any*

Set external-mixer bias. See `mixer_bias`.

 *property *mixer_mode*: Any*

Select the mixer mode: internal mixer, or an external mixer supplied by the user. Accepts enum `MixerMode` or the strings `INT`, `EXT`.

 peak_preselector()

Peaks the preselector on the HP 8561B Spectrum Analyzer.

Before running PP, verify that the whole frequency span is in high band, put the desired trace in clear-write mode, and place a marker on the desired signal. PP zooms to zero span, peaks preselector tracking, and returns to the original position. Read the updated preselector peaking number with PSDAC. Any commands after PP wait until preselector peaking is complete.

 *property *preselector_dac_number*: Any*

Set or read the preselector peak DAC number for an HP 8561B Spectrum Analyzer.

Type: `int`

 set_signal_identification_to_center_frequency()

Set the center frequency to the frequency returned by SIGID.

For this command to run correctly, SIGID must be in AUTO mode and must have found a valid result. Use SIGID for signals greater than 18 GHz {i.e., in external mixing mode). On an HP 8561B, SIGID and IDCF can also be used with signals less than 6.5 GHz.

 *property *signal_identification*: Any*

Control signal identification for external mixing frequency bands. Two methods are available. AUTO uses the image response method to find correct mixer responses. Put a marker on the desired signal, then set `signal_identification = 'AUTO'`. A correct response's frequency appears in the active function block. Use AUTO before calling `signal_identification_to_center_frequency()`. The MAN method shifts responses horizontally and vertically. A correct response moves horizontally by less than 80 kHz. For MAN accuracy, keep the frequency span under 20 MHz. True means manual mode is active; False means auto mode is active or `signal_identification` is off.

 *property *signal_identification_frequency*: Any*

Measure the frequency for the most recently identified signal. After an instrument preset or invalid signal identification, IDFREQ returns a "0".

 unlock_harmonic_number()

Release harmonic-number lock so frequencies and spans outside the locked harmonic number's range can be selected.

After HNUNLK is executed, a sweep across the desired span can use more than one harmonic. For example, sweeping 18 GHz to 40 GHz makes the analyzer sweep automatically using 6Ч first and then 8Ч.
