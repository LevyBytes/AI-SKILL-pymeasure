### PyMeasure scientific package

 (Figure: PyMeasure Scientific package)

PyMeasure helps configure and run scientific measurements. It provides instrument classes plus experiment-procedure tooling, including graphical interfaces for live plots and experiment queues. These two areas can be used independently, and together they support advanced measurements with relatively little code.

The [Quick Start guide](https://pymeasure.readthedocs.io/en/latest/quick_start.html) shows how to install Python and PyMeasure. After that, review the [instruments that are available for use](https://pymeasure.readthedocs.io/en/latest/api/instruments/index.html).

PyMeasure remains actively developed, so report problems through the [Issues page](https://github.com/pymeasure/pymeasure/issues).
