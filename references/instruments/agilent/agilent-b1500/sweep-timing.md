# pymeasure.instruments.agilent.agilentB1500.AgilentB1500.sweep_timing

[Owning PyMeasure class, adapter and connection contract](overview.md)

sweep_timing(*hold*, *delay*, *step_delay=0*, *step_trigger_delay=0*, *measurement_trigger_delay=0*)

Configure timing values for staircase or multi channel sweep operation. (`WT`)

Parameters:

- **hold** (*float*) – Hold time

- **delay** (*float*) – Delay time

- **step_delay** (*float*) – Step delay duration, defaults to 0

- **step_trigger_delay** (*float*) – Trigger delay duration, defaults to 0

- **measurement_trigger_delay** (*float*) – Measurement trigger delay duration, defaults to 0
