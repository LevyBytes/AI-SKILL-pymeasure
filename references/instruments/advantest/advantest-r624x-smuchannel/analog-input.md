# pymeasure.instruments.advantest.advantestR624X.SMUChannel.analog_input

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *analog_input*: Any*

Turn the rear-panel analog input terminal (ANALOG INPUT) ON or OFF (`IAN`).

Type:

int

1. Turn off the analog input.

2. Analog input ON, gain x1.

3. Analog input ON, gain x2.5.
