# pymeasure.instruments.pendulum.cnt91.CNT91.configure_frequency_array_measurement

[Owning PyMeasure class, adapter and connection contract](overview.md)

configure_frequency_array_measurement(*n_samples*, *channel*, *back_to_back=True*)

Set up the counter to make a measurement array.

Parameters:

- **n_samples** – Count of samples

- **channel** – Channel for measurement (A, B, C, E, INTREF)

- **back_to_back** – When True, run the buffer measurement back-to-back. (default: `True`)
