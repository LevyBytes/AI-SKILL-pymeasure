# pymeasure.instruments.hp.HP8560A.source_power_sweep

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *source_power_sweep*: Any*

Configure power-sweep operation, where the tracking generator output power moves across the selected power-sweep range. The starting source power level comes from the `source_power` command, and the generator output follows the spectrum analyzer sweep rate.

Type: `str, float`

Note

Available only on an HP 8560A Option 002.
