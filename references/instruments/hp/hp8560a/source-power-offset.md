# pymeasure.instruments.hp.HP8560A.source_power_offset

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *source_power_offset*: Any*
Set the displayed-power offset for the built-in tracking generator so the display matches the power measured at the spectrum analyzer input. Use this to include system losses, for example cable loss, or gains, for example preamplifier gain, so the indicated value reflects the actual power delivered to the device under test.

Type: `int`

Note

Available only on an HP 8560A Option 002.
