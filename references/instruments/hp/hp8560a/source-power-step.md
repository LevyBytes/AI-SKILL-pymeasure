# pymeasure.instruments.hp.HP8560A.source_power_step

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *source_power_step*: Any*

Set how large each increment is for source power level adjustments, source power offset adjustments, and the power-sweep range. Range: 0.1 Е 12.75 DB with 0.05 steps.

Type: `float`

Note

Available only on an HP 8560A Option 002.
