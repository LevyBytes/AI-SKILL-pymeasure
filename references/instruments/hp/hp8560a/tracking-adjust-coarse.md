# pymeasure.instruments.hp.HP8560A.tracking_adjust_coarse

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *tracking_adjust_coarse*: Any*

Set the coarse frequency adjustment for the built-in tracking-generator oscillator. When enabled, the setting uses digital-to-analogconverter (DAC) values from 0 to 255. For fine control, see the `tracking_adjust_fine` command description.

Type: `int`

Note

Available only on an HP 8560A Option 002.
