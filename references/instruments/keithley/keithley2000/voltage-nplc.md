# pymeasure.instruments.keithley.Keithley2000.voltage_nplc

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *voltage_nplc*: Any*

For DC voltage measurements, set or read the number of power line cycles (NPLC), controlling integration period and measurement speed. Valid values are 0.01 to 10; 0.1, 1, and 10 correspond to Fast, Medium, and Slow.
