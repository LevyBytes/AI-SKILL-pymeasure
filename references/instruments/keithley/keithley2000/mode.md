# pymeasure.instruments.keithley.Keithley2000.mode

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *mode*: Any*

Set or read the measurement configuration mode string. Use `current` (DC) or `current ac` for current, `voltage` (DC) or `voltage ac` for voltage, and `resistance` (2-wire) or `resistance 4W` (4-wire) for resistance. Other accepted values are `period`, `temperature`, `diode`, and `frequency`.
