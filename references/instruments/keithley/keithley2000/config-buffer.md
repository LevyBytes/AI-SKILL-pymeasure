# pymeasure.instruments.keithley.Keithley2000.config_buffer

[Owning PyMeasure class, adapter and connection contract](overview.md)

config_buffer(*points=64*, *delay=0*)

Prepare the measurement buffer for a chosen point count, using the requested delay between acquisitions.

Parameters:

- **points**: Number of points configured for the buffer. (default: `64`)

- **delay**: Delay time in seconds. (default: `0`)
