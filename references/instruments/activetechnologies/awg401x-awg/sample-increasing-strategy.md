# pymeasure.instruments.activetechnologies.AWG401x_AWG.sample_increasing_strategy

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *sample_increasing_strategy*: Any*

Set or query the Sample Increasing Strategy. The “Sample increasing strategy” parameter chooses how to extend a waveform when its length is less than the sequencer entry length. Allowed settings: INTER&lt;POLATION&gt;, RETURN&lt;ZERO&gt;, HOLD&lt;LAST&gt;, SAMPLESM&lt;ULTIPLICATION&gt;
