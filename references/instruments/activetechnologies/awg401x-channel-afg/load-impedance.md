# pymeasure.instruments.activetechnologies.AWG401x.ChannelAFG.load_impedance

[Owning PyMeasure class, adapter and connection contract](overview.md)

*property *load_impedance*: Any*

Set or query the output load impedance for the specified channel. The chosen value is applied to amplitude, offset, and high/low level settings. The impedance may be any value from 1 Ω to 1 MΩ. The default value is 50 Ω.
